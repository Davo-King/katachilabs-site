01 / Features

What it does

Organise

  • Organise bookmarks into categories and columns
  • Pinned, Favourites and Projects
  • Light and dark mode, with six colour themes

Find and save

  • Fast search (press /), with your own default search engine for the web
  • Save the current page, or all open tabs, with Alt+Shift+B
  • Import your Chrome bookmarks, back up and restore with a JSON file

03 / Privacy

Private by design

Local storage only

Everything you save stays on your device in Chrome's extension storage. No account, no tracking, no servers. Bookmarks do not sync between computers on their own; move them with a backup file.
